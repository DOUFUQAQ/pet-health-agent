# 网表连接关系（用于 EDA 画原理图参考）

## 一、网络定义

| 网络名 | 说明 |
|--------|------|
| VCC_3V3 | 3.3V 电源网络 |
| VCC_5V / VBAT | 电池/5V 电源网络 |
| GND | 公共地 |
| SDA | I2C 数据线 |
| SCL | I2C 时钟线 |
| DHT_DATA | DHT22 数据线 |
| SERVO_PWM | 舵机控制 PWM |
| BAT_ADC | 电池电压检测 ADC |
| MAX_INT | MAX30102 中断 |
| LED_CTRL | LED 控制 |

## 二、完整网络连接表

### 网络：VCC_3V3
```
AMS1117.VOUT ─── ESP32.3V3 ─── MLX90614.VCC ─── MAX30102.VIN
                 ─── MPU6050.VCC ─── DHT22.VCC
                 ─── R_SDA.端1 ─── R_SCL.端1 ─── R_DHT.端1
                 ─── C_OUT.+ ─── C3(去耦).端1
```

### 网络：VBAT / VCC_5V
```
TP4056.OUT+ ─── AMS1117.VIN ─── SG90.VCC(红线)
             ─── C_IN.+ ─── R4(分压上).端1 ─── C4(舵机).+
             ─── SW1.COM (电源开关)
```

### 网络：GND
```
ESP32.GND ─── MLX90614.GND ─── MAX30102.GND ─── MPU6050.GND
          ─── MPU6050.AD0 ─── DHT22.GND ─── SG90.GND(棕线)
          ─── AMS1117.GND ─── TP4056.OUT-
          ─── C_IN.- ─── C_OUT.- ─── C3.- ─── C4.-
          ─── C_ADC.- ─── R5(分压下).端2 ─── D1.阴极
          ─── 18650.负极
```

### 网络：SDA
```
ESP32.GPIO21 ─── MLX90614.SDA ─── MAX30102.SDA ─── MPU6050.SDA
             ─── R_SDA.端2 (4.7kΩ 上拉到 VCC_3V3)
```

### 网络：SCL
```
ESP32.GPIO22 ─── MLX90614.SCL ─── MAX30102.SCL ─── MPU6050.SCL
             ─── R_SCL.端2 (4.7kΩ 上拉到 VCC_3V3)
```

### 网络：DHT_DATA
```
ESP32.GPIO27 ─── DHT22.DATA(Pin2) ─── R_DHT.端2 (10kΩ 上拉到 VCC_3V3)
```

### 网络：SERVO_PWM
```
ESP32.GPIO18 ─── SG90.SIGNAL(橙线)
```

### 网络：BAT_ADC
```
R4.端2 ─── R5.端1 ─── ESP32.GPIO36 ─── C_ADC.端1 (0.1µF 到 GND)
```

### 网络：MAX_INT
```
ESP32.GPIO15 ─── MAX30102.INT
```

### 网络：LED_CTRL
```
ESP32.GPIO4 ─── R6.端1 (220Ω) ─── D1.阳极
```

## 三、立创EDA 元件库搜索关键词

| 模块 | 立创EDA 搜索关键词 | 封装 |
|------|-------------------|------|
| ESP32-WROOM-32 | "ESP32-WROOM-32" 或 "ESP32-DevKitC" | 邮票孔 / 排针 |
| MLX90614 | "MLX90614ESF" | TO-39-4 (裸芯片) / 搜 "GY-906" (模块) |
| MAX30102 | "MAX30102" | OLGA-14 (裸芯片) / 自建模块封装 |
| MPU6050 | "MPU-6050" | QFN-24 (裸芯片) / 搜 "GY-521" (模块) |
| DHT22 | "DHT22" 或 "AM2302" | 4-pin SIP |
| AMS1117-3.3 | "AMS1117-3.3" | SOT-223 |
| TP4056 | "TP4056" | SOP-8 (芯片) / 模块 |

**模块式方案：** 如果用现成模块（GY-906, GY-521 等），在立创EDA中自建封装，画 4-pin 或 6-pin 2.54mm 排针焊盘即可。

## 四、自建模块封装尺寸参考

### 4-pin 传感器模块排母 (MLX90614 GY-906)
```
  引脚间距: 2.54mm
  焊盘: 圆形, 直径1.6mm, 孔径1.0mm
  
  ○ ── VCC
  ○ ── GND
  ○ ── SDA
  ○ ── SCL
  
  总长: 2.54 × 3 = 7.62mm
```

### 5-pin 传感器模块排母 (MAX30102)
```
  ○ ── VIN
  ○ ── GND
  ○ ── INT
  ○ ── SDA
  ○ ── SCL
  
  总长: 2.54 × 4 = 10.16mm
```

### 8-pin 传感器模块排母 (MPU6050 GY-521)
```
  ○ ── VCC
  ○ ── GND
  ○ ── SCL
  ○ ── SDA
  ○ ── XDA
  ○ ── XCL
  ○ ── AD0
  ○ ── INT
  
  总长: 2.54 × 7 = 17.78mm
```

### 3-pin 舵机接口 (SG90)
```
  引脚间距: 2.54mm
  
  ○ ── SIGNAL (橙)
  ○ ── VCC (红)
  ○ ── GND (棕)
  
  总长: 2.54 × 2 = 5.08mm
```

## 五、设计验证清单

原理图画完后逐条检查：

- [ ] ESP32 的 3V3 和 GND 已连接
- [ ] I2C 总线有且仅有一对 4.7kΩ 上拉到 3.3V
- [ ] MLX90614 连接到 SDA(GPIO21) 和 SCL(GPIO22)
- [ ] MAX30102 连接到 SDA(GPIO21) 和 SCL(GPIO22)
- [ ] MPU6050 连接到 SDA(GPIO21) 和 SCL(GPIO22)，AD0 接 GND
- [ ] DHT22 DATA 连 GPIO27，有 10kΩ 上拉
- [ ] SG90 信号线连 GPIO18，电源接 5V/VBAT
- [ ] 电池分压电路连 GPIO36 (ADC1_CH0)
- [ ] AMS1117 输入输出各有 10µF 电容
- [ ] 100µF 电容在舵机电源旁
- [ ] 没有使用 GPIO6~11（Flash专用）
- [ ] 没有使用 GPIO1, GPIO3（UART0，调试串口）
- [ ] ESP32 天线端无铜皮覆盖
- [ ] 所有 ERC/DRC 检查通过
