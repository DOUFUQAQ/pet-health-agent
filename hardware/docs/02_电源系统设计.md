## 二、TP4056 充电模块接线

### 模块引脚 (带DW01保护版)

| TP4056模块引脚 | 连接到 | 说明 |
|---------------|--------|------|
| IN+ (USB 5V) | USB接口 VBUS | 充电输入 5V |
| IN- (USB GND) | USB接口 GND | 充电输入地 |
| BAT+ | 18650 正极 | 电池正极 |
| BAT- | 18650 负极 | 电池负极 |
| OUT+ | AMS1117 VIN + 5V总线 | 带保护输出正极 |
| OUT- | GND 总线 | 带保护输出地 |

```
  ┌────────────────────────────────────────────────────┐
  │                  TP4056 模块                        │
  │                (带 DW01 保护)                       │
  │                                                    │
  │  USB-C/Micro ──> IN+   OUT+ ──> 到 AMS1117 + 5V线 │
  │                  IN-   OUT- ──> GND总线             │
  │                  BAT+  BAT-                        │
  │                   │      │                         │
  │                   │      │                         │
  └───────────────────┼──────┼─────────────────────────┘
                      │      │
                 ┌────┴──────┴────┐
                 │   18650 电池    │
                 │   ⊕        ⊖   │
                 └────────────────┘
```

### ⚠️ 关键设计要点
1. **必须使用带 DW01 保护IC 的 TP4056 模块**，防止电池过充过放
2. TP4056 的充电电流由 PROG 电阻决定，默认 1.2kΩ = 1A 充电，可换成 2kΩ = 580mA 更安全
3. **不要同时给 ESP32 的 VIN 和 TP4056 供 5V**，选一个路径

## 三、AMS1117-3.3V 稳压电路

```
                      AMS1117-3.3
                    ┌─────────────┐
  VBAT (3.7~4.2V)──┤ VIN    VOUT ├──── 3.3V 输出
                    │             │
             GND ───┤ GND         │
                    └─────────────┘
                    │             │
              ┌─────┘             └─────┐
              │                         │
         ┌────┴────┐              ┌─────┴────┐
         │ 10µF    │              │ 10µF     │
         │ 电解    │              │ 电解     │
         │ 电容    │              │ 电容     │
         └────┬────┘              └─────┬────┘
              │                         │
              GND                      GND
```

| 元件 | 值 | 说明 |
|------|-----|------|
| C1 (输入侧) | 10µF/16V 电解电容 | 输入滤波，紧贴 AMS1117 放 |
| C2 (输出侧) | 10µF/16V 电解电容 | 输出滤波，紧贴 AMS1117 放 |
| C3 (输出侧) | 0.1µF 陶瓷电容 | 高频去耦 |

**注意：** AMS1117 的 Dropout 约 1.1V，18650 电池放电到 3.3V + 1.1V = 4.4V 以下时输出开始不稳。实测 3.7V 输入时 3.3V 输出仍可工作（dropout 在低电流下实际更低约 0.5V），但电池低于 3.5V 需要告警。

## 四、电池电压检测电路

通过分压电阻将 4.2V 降到 ESP32 ADC 安全范围（0~3.3V）。

```
  VBAT (3.7~4.2V)
       │
      ┌┴┐
      │ │ R1 = 100kΩ
      └┬┘
       │
       ├──────── ESP32 GPIO36 (ADC1_CH0)
       │
      ┌┴┐
      │ │ R2 = 100kΩ
      └┬┘
       │
      GND
```

**分压比：** R2 / (R1 + R2) = 100k / 200k = 0.5
- 满电 4.2V → ADC读 2.1V
- 低电 3.0V → ADC读 1.5V
- ESP32 ADC 量程 0~3.3V，完全安全

**固件中计算公式：**
```c
float battery_voltage = (adc_reading / 4095.0) * 3.3 * 2.0;
// 乘以2是因为分压比0.5
int battery_percent = map(battery_voltage * 100, 300, 420, 0, 100);
```

**额外加 0.1µF 电容在 GPIO36 和 GND 之间**，滤除 ADC 采样噪声。

## 五、功耗估算

| 模块 | 工作电流 | 待机电流 | 说明 |
|------|---------|---------|------|
| ESP32 (Wi-Fi active) | 160~260mA | 10µA (deep sleep) | 最大功耗源 |
| MLX90614 | 1.5mA | 2.5µA | 极低功耗 |
| MAX30102 | 0.6mA (测量) | 0.7µA | 低功耗 |
| MPU6050 | 3.8mA | 5µA | 低功耗 |
| DHT22 | 1.5mA (测量) | 50µA | 间歇采集 |
| SG90 (运动中) | 100~250mA | 10mA (保持) | 仅喂食时启用 |
| AMS1117 | 5mA (静态) | - | 自身损耗 |
| **总计(不含舵机)** | **~270mA** | - | - |
| **总计(含舵机)** | **~500mA** | - | - |

**18650 电池(2500mAh) 续航估算：**
- 持续采集模式：2500 / 270 ≈ **9 小时**
- 间歇采集(每10秒采一次)：约 **24~48 小时**
- 深度睡眠 + 定时唤醒(每分钟)：约 **数周**
