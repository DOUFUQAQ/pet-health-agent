## 二、PCB 板子规格建议

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 板层数 | **2层** | 双面板，顶层走信号、底层铺地 |
| 板厚 | 1.6mm | 标准厚度 |
| 铜厚 | 1oz (35µm) | 标准 |
| 板材 | FR-4 | 标准玻纤板 |
| 外形尺寸 | **50mm × 70mm** | 适合做宠物项圈内嵌 |
| 表面工艺 | HASL (有铅喷锡) | 最便宜，手焊友好 |
| 线宽/线距 | ≥ 0.254mm (10mil) | 嘉立创免费工艺支持 |
| 最小过孔 | 0.3mm孔径 / 0.6mm焊盘 | 标准 |

## 三、PCB 布局策略

### 3.1 模块区域划分

### 3.2 布局原则

1. **ESP32 天线区域净空**
   - ESP32-WROOM-32 的 PCB 天线在模块末端
   - 天线下方及周围 10mm 范围内 **禁止铺铜、禁止走线、禁止放元件**
   - 否则 Wi-Fi 信号严重衰减

2. **电源区域集中**
   - TP4056、AMS1117、电池座放在一起
   - 大电流走线加宽到 **0.5mm ~ 1mm**
   - 电源走线远离 I2C 信号线

3. **I2C 走线**
   - SDA 和 SCL 走线尽量平行、等长
   - 线宽 0.254mm 即可（信号电流很小）
   - 上拉电阻紧贴 ESP32 放置
   - 避免与电源线平行长距离走线

4. **去耦电容紧贴芯片**
   - 每个 IC 的 VCC 和 GND 之间放 0.1µF 去耦电容
   - **焊盘到芯片引脚距离 < 5mm**

5. **底层铺铜接地**
   - 整个底层铺满 GND 铜皮
   - 每个模块 GND 引脚附近打过孔连接到底层地

## 四、关键走线规则

| 走线类型 | 线宽 | 说明 |
|---------|------|------|
| 3.3V 电源线 | 0.5mm ~ 0.8mm | 载流约 300mA |
| 5V / VBAT 线 | 0.8mm ~ 1.0mm | 载流可达 500mA (舵机) |
| GND 线 | 0.8mm + 底层铺铜 | 地线越粗越好 |
| I2C (SDA/SCL) | 0.254mm | 低速信号 |
| DHT22 DATA | 0.254mm | 低速信号 |
| PWM (舵机) | 0.254mm | 低速信号 |
| ADC (电池检测) | 0.254mm | 模拟信号，远离干扰源 |

## 五、焊接方式建议

### 方案A：模块式（推荐新手）
- PCB 上只留排母座，传感器用模块直接插拔
- 优点：调试方便、模块坏了可以换
- 缺点：体积大

### 方案B：芯片直焊式
- PCB 上直接焊 MLX90614ESF (TO-39)、MAX30102 裸芯片(OLGA-14)、MPU6050 (QFN-24)
- 优点：体积小、成本低
- 缺点：需要热风枪和较高焊接技能

**推荐方案 A**，出成果最快。

## 六、打板下单检查清单

在导出 Gerber 文件下单之前确认：

- [ ] 所有网络连接正确（运行 DRC 检查无错误）
- [ ] ESP32 天线区域无铜皮无走线
- [ ] 电源线宽 ≥ 0.5mm
- [ ] I2C 只有一对 4.7kΩ 上拉（不是每个传感器一对）
- [ ] 所有去耦电容紧贴芯片
- [ ] 底层有完整地平面
- [ ] 所有排针/排母的间距是 2.54mm
- [ ] 18650 电池座尺寸和方向正确
- [ ] 电源开关在方便操作的位置
- [ ] USB-C 接口在板边，插拔无干涉
- [ ] 丝印层标注清晰（模块名称、引脚定义、极性标记）

## 八、立创EDA 操作步骤概要

1. **新建工程** → 选"原理图+PCB"
2. **画原理图**：
   - 从元件库搜索 "ESP32-WROOM-32"、"MLX90614"、"MAX30102"、"MPU6050" 等
   - 按照本文档的连接关系画线
   - 运行 ERC (电气规则检查)
3. **转换PCB**：
   - 原理图完成后点击"设计 → 原理图转PCB"
   - 自动生成所有焊盘和网络
4. **布局布线**：
   - 按本文档的布局策略摆放元件
   - 手动走线或使用自动布线
   - 底层铺铜设为 GND
   - 运行 DRC (设计规则检查)
5. **导出制造文件**：
   - 点击"制造 → 下单/Gerber导出"
   - 直接嘉立创下单
