# 接线实操步骤（面包板验证 → PCB）

## 一、面包板验证（先验证再打板！）

**在画 PCB 之前，强烈建议先用面包板和杜邦线把电路搭起来验证功能。**

### 所需工具
- 面包板 (830孔) × 1
- 杜邦线（公对母、公对公） × 若干
- USB 数据线（给 ESP32 供电 + 烧录程序）
- 万用表（量电压、检查通断）

### 步骤1：ESP32 上电测试

1. 将 ESP32 DevKit 插在面包板中间（跨越中间沟槽）
2. USB 连接电脑
3. 打开 Arduino IDE → 工具 → 端口，确认识别到 COM 口
4. 烧录 Blink 程序确认工作正常

### 步骤2：I2C 总线搭建

```
面包板接线：

ESP32 3V3   ──────── 面包板 + 电源轨
ESP32 GND   ──────── 面包板 - 地轨

I2C 上拉电阻（只需一对！）：
  面包板 + 轨 ──┤ 4.7kΩ ├── 连到 SDA 总线行
  面包板 + 轨 ──┤ 4.7kΩ ├── 连到 SCL 总线行

ESP32 GPIO21 ── 杜邦线 ── SDA 总线行
ESP32 GPIO22 ── 杜邦线 ── SCL 总线行
```

### 步骤3：逐一连接传感器

**⚠️ 每连一个传感器就跑一次 I2C 扫描程序，确认地址正确再接下一个！**

#### 3a. 接 MLX90614 (GY-906)
```
GY-906 VCC ── 3.3V (+轨)
GY-906 GND ── GND  (-轨)
GY-906 SDA ── SDA 总线行
GY-906 SCL ── SCL 总线行
```
→ 跑 I2C 扫描 → 应出现 0x5A

#### 3b. 接 MAX30102
```
MAX30102 VIN ── 3.3V (+轨)
MAX30102 GND ── GND  (-轨)
MAX30102 SDA ── SDA 总线行
MAX30102 SCL ── SCL 总线行
MAX30102 INT ── GPIO15 (可选)
```
→ 跑 I2C 扫描 → 应出现 0x57 和 0x5A

**如果 0x57 没出现：**
1. 量测模块上 SDA 线的上拉电压，如果是 1.8V 而非 3.3V，模块有硬件问题
2. 解决方法：用小刀切断模块上连接到 1.8V 的走线，飞线到 3.3V

#### 3c. 接 MPU6050 (GY-521)
```
GY-521 VCC ── 3.3V (+轨)
GY-521 GND ── GND  (-轨)
GY-521 SDA ── SDA 总线行
GY-521 SCL ── SCL 总线行
GY-521 AD0 ── GND  (-轨)    ← 关键！地址选为0x68
```
→ 跑 I2C 扫描 → 应出现 0x57、0x5A、0x68

### 步骤4：接 DHT22
```
DHT22 VCC (Pin1) ── 3.3V (+轨)
DHT22 DATA(Pin2) ── GPIO27
DHT22 GND (Pin4) ── GND  (-轨)

额外：10kΩ 电阻连接 DATA(Pin2) 到 3.3V (+轨)
```
→ 跑 DHT22 示例程序确认读数正常

### 步骤5：接 SG90 舵机
```
SG90 红色线   ── ESP32 VIN (5V, 从USB取电)
SG90 棕色线   ── GND  (-轨)
SG90 橙色线   ── GPIO18
```
→ 跑 Servo 扫描程序（0°→90°→180°→0°）确认转动正常

### 步骤6：综合测试

所有传感器连好后，烧录综合测试固件，确认：
- [ ] I2C 扫描到 3 个地址 (0x57, 0x5A, 0x68)
- [ ] MLX90614 读出合理温度值（室温 20~30°C）
- [ ] MAX30102 手指按上去有心率读数
- [ ] MPU6050 读出加速度值（静止时 Z 轴约 1g = 9.8 m/s²）
- [ ] DHT22 读出温湿度值
- [ ] SG90 能受控转动
- [ ] Wi-Fi 能连接
- [ ] MQTT 能发消息

**面包板全部验证通过后，再画 PCB！**

## 三、常见问题排查

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| I2C 扫描无设备 | SDA/SCL 接反 | 检查线序 |
| I2C 扫描无设备 | 上拉电阻未接 | 确认 4.7kΩ 在位 |
| I2C 扫描无设备 | 模块未供电 | 用万用表量 VCC |
| 只有部分设备 | 地址冲突或模块损坏 | 逐一排查 |
| MAX30102 不响应 | 上拉接到 1.8V | 修改模块走线到 3.3V |
| DHT22 读数全0 | 缺少上拉电阻 | 加 10kΩ 上拉 |
| DHT22 校验失败 | 线太长或干扰 | 缩短杜邦线 |
| 舵机抖动 | 供电不足 | 加 100µF 电容或独立供电 |
| 舵机不转 | PWM引脚错误 | 确认 GPIO18 |
| ESP32 反复重启 | 电源不稳或短路 | 检查所有连线 |
| Wi-Fi 信号差 | 天线被遮挡 | ESP32天线部分悬空 |
| ADC 读数不准 | 没接滤波电容 | 加 0.1µF 在 ADC 引脚 |
