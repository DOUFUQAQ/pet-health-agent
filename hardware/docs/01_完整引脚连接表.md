## 二、各模块详细连接

### 2.1 MLX90614 非接触红外测温模块 (U2)

| MLX90614 引脚 | 连接到 | 说明 |
|---------------|--------|------|
| VCC | 3.3V 电源总线 | 供电电压 3.3V |
| GND | GND 地线总线 | 公共地 |
| SDA | ESP32 GPIO21 | I2C 数据线 (地址 0x5A) |
| SCL | ESP32 GPIO22 | I2C 时钟线 |

**外围电路：**
- VCC → 0.1µF 去耦电容 → GND（紧贴模块放置）
- **注意：** 大多数 MLX90614 模块（如 GY-906）已内置上拉电阻和滤波电容，若使用模块板则无需额外元件

```
               ┌─────────────┐
   3.3V ───────┤ VCC         │
               │             │
   GND ────────┤ GND    ◉    │← 红外感应窗口（朝向宠物）
               │        镜头 │
   GPIO21 ─────┤ SDA         │
               │             │
   GPIO22 ─────┤ SCL         │
               └─────────────┘
                  MLX90614
                 (GY-906模块)
```

### 2.2 MAX30102 心率血氧模块 (U3)

| MAX30102 模块引脚 | 连接到 | 说明 |
|-------------------|--------|------|
| VIN | 3.3V 电源总线 | 模块输入 3.3V~5V，内部1.8V LDO |
| GND | GND 地线总线 | 公共地 |
| SDA | ESP32 GPIO21 | I2C 数据线 (地址 0x57) |
| SCL | ESP32 GPIO22 | I2C 时钟线 |
| INT | ESP32 GPIO15 | 中断输出（可选，数据就绪通知） |
| IRD | 悬空(NC) | 红外LED控制（模块内部已连） |
| RD | 悬空(NC) | 红色LED控制（模块内部已连） |

**⚠️ 重要硬件问题：**
部分廉价 MAX30102 模块的 I2C 上拉电阻接到了 1.8V 而非 3.3V，导致 ESP32 无法扫描到该设备。解决方法：
1. 用万用表量测模块上 SDA/SCL 上拉到的电压
2. 如果是 1.8V，需要用刀片切断 1.8V 走线，飞线到 3.3V
3. 或直接购买标注 "3.3V pull-up" 的版本

```
               ┌──────────────┐
   3.3V ───────┤ VIN          │
               │              │
   GND ────────┤ GND   ┌──┐  │
               │       │◉◉│  │← 光电传感器窗口
   GPIO21 ─────┤ SDA   │红外│  │  （需贴合宠物皮肤）
               │       └──┘  │
   GPIO22 ─────┤ SCL          │
               │              │
   GPIO15 ─────┤ INT (可选)   │
               │              │
          NC ──┤ IRD          │
          NC ──┤ RD           │
               └──────────────┘
                  MAX30102 模块
```

### 2.3 MPU6050 六轴加速度计/陀螺仪 (U4)

| MPU6050 模块引脚 | 连接到 | 说明 |
|------------------|--------|------|
| VCC | 3.3V 电源总线 | 供电 3.3V（模块兼容5V，但用3.3V更好） |
| GND | GND 地线总线 | 公共地 |
| SDA | ESP32 GPIO21 | I2C 数据线 |
| SCL | ESP32 GPIO22 | I2C 时钟线 |
| AD0 | GND | 地址选择：接GND=0x68，接VCC=0x69 |
| INT | ESP32 GPIO4（可选） | 运动中断检测 |
| XDA | 悬空(NC) | 辅助I2C数据（不用） |
| XCL | 悬空(NC) | 辅助I2C时钟（不用） |

```
               ┌─────────────┐
   3.3V ───────┤ VCC         │
               │             │
   GND ────┬───┤ GND         │
           │   │             │
   GPIO21 ─┼───┤ SDA         │
           │   │             │
   GPIO22 ─┼───┤ SCL         │
           │   │             │
   GND ────┘───┤ AD0         │← 接GND = 地址0x68
               │             │
   GPIO4 ──────┤ INT (可选)  │
               │             │
          NC ──┤ XDA         │
          NC ──┤ XCL         │
               └─────────────┘
                 MPU6050 模块
                (GY-521模块)
```

### 2.4 DHT22 温湿度传感器 (U5)

| DHT22 引脚 | 连接到 | 说明 |
|------------|--------|------|
| VCC (Pin 1) | 3.3V | 供电 |
| DATA (Pin 2) | ESP32 GPIO27 | 单线数据 |
| NC (Pin 3) | 悬空 | 空脚 |
| GND (Pin 4) | GND | 公共地 |

**外围电路：**
- DATA 引脚到 VCC 之间接 **10kΩ 上拉电阻**（必须）
- VCC → 0.1µF 去耦电容 → GND

```
               ┌──────────┐
               │  DHT22   │
               │ ┌──────┐ │
   3.3V ───────┤1│      │4├──── GND
               │ │ 栅格 │ │
   GPIO27 ─┬───┤2│      │3├──── NC (悬空)
            │  │ └──────┘ │
   10kΩ     │  └──────────┘
   ┌────────┘
   │
   3.3V
```

### 2.5 SG90 舵机 - 模拟喂食器 (U6)

| SG90 线色 | 连接到 | 说明 |
|-----------|--------|------|
| 红色 | 5V (VIN / TP4056输出) | 供电 **必须5V**，不能用3.3V |
| 棕色/黑色 | GND | 公共地 |
| 橙色/黄色 | ESP32 GPIO18 | PWM控制信号 |

**⚠️ 注意：**
- 舵机工作电压 4.8~6V，**不能接 3.3V**
- 直接从 ESP32 的 VIN (5V) 或电池升压后取电
- 如果舵机与 ESP32 共用电源，要加 **100µF 电解电容** 在 5V 和 GND 之间抑制电流尖峰

```
   5V ──────────── 红色线 ─┐
                           │ SG90
   GND ─────────── 棕色线 ─┤ 舵机
                           │
   GPIO18 (PWM) ── 橙色线 ─┘
```

### 2.6 状态指示 LED (可选)

| LED | 连接到 | 说明 |
|-----|--------|------|
| 阳极(长脚) | ESP32 GPIO4 → 220Ω电阻 | 数据上报指示 |

                       LED

## 三、完整引脚分配汇总

| ESP32 GPIO | 功能 | 连接模块 | 协议 |
|------------|------|---------|------|
| GPIO21 | SDA | MLX90614 + MAX30102 + MPU6050 | I2C |
| GPIO22 | SCL | MLX90614 + MAX30102 + MPU6050 | I2C |
| GPIO27 | DATA | DHT22 | 单线协议 |
| GPIO18 | PWM | SG90 舵机 | PWM |
| GPIO15 | INT | MAX30102 中断（可选） | 数字输入 |
| GPIO4 | INT / LED | MPU6050 中断 或 LED指示 | 数字 |
| GPIO36 | ADC | 电池电压检测（分压） | ADC1_CH0 |
| GPIO2 | LED | 板载LED（调试用） | 数字输出 |

**保留/避免使用的引脚：**
- GPIO6~11：内部 Flash，**绝对不能用**
- GPIO0：启动模式选择，避免外接
- GPIO1/3：UART0 TX/RX（串口调试），保持空闲
- GPIO12：启动电压选择 strapping pin，避免上拉
