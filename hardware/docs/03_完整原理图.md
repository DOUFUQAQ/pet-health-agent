## 三、I2C 地址确认测试

画完原理图、焊完板子后，第一件事是跑 I2C 扫描确认三个传感器都能识别到：

```c
// Arduino IDE 中运行
#include <Wire.h>

void setup() {
    Serial.begin(115200);
    Wire.begin(21, 22); // SDA=21, SCL=22
    
    Serial.println("I2C Scanner Starting...");
    
    for (byte addr = 1; addr < 127; addr++) {
        Wire.beginTransmission(addr);
        if (Wire.endTransmission() == 0) {
            Serial.printf("Found device at 0x%02X", addr);
            if (addr == 0x5A) Serial.print(" <- MLX90614");
            if (addr == 0x57) Serial.print(" <- MAX30102");
            if (addr == 0x68) Serial.print(" <- MPU6050");
            Serial.println();
        }
    }
    Serial.println("Scan complete.");
}

void loop() {}
```

**预期输出：**
```
I2C Scanner Starting...
Found device at 0x57 <- MAX30102
Found device at 0x5A <- MLX90614
Found device at 0x68 <- MPU6050
Scan complete.
```

如果缺少某个地址，检查：
1. 供电是否正确（用万用表量 VCC 引脚）
2. SDA/SCL 有没有接反
3. 上拉电阻是否焊好
4. MAX30102 的上拉电阻是否接到了 3.3V（而非 1.8V）
