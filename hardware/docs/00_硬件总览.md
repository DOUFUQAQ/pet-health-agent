# 宠物健康监测系统 - 硬件设计文档

## 一、系统硬件总览

### 1.1 核心模块清单

| 编号 | 模块 | 型号 | I2C地址 | 电压 | 用途 |
|------|------|------|---------|------|------|
| U1 | 主控MCU | ESP32-WROOM-32 | - | 3.3V | Wi-Fi + MQTT通信 + 传感器控制 |
| U2 | 红外测温 | MLX90614ESF | 0x5A | 3.3V | 非接触式宠物体温检测 |
| U3 | 心率血氧 | MAX30102 | 0x57 | 1.8V(内核)/3.3V(LED) | 光电心率 + SpO2 检测 |
| U4 | 六轴IMU | MPU6050 | 0x68 | 3.3V | 加速度+陀螺仪(活动量检测) |
| U5 | 温湿度 | DHT22/AM2302 | - (单线) | 3.3V | 环境温湿度 |
| U6 | 舵机 | SG90 | - (PWM) | 5V | 模拟自动喂食器 |
| U7 | 充电管理 | TP4056 + DW01 | - | 5V输入 | 18650锂电池充电保护 |
| U8 | 稳压器 | AMS1117-3.3 | - | 3.3V输出 | 锂电池→3.3V稳压 |
| U9 | 电池 | 18650锂电池 | - | 3.7V(标称) | 系统供电 |

### 1.2 I2C 总线架构

三个I2C传感器共享同一条总线，地址互不冲突：

```
                     4.7kΩ      4.7kΩ
            3.3V ────┤├──┬──────┤├──┬──── 3.3V
                     │   │      │   │
ESP32 GPIO21 (SDA) ──┼───┴──────┼───┤
ESP32 GPIO22 (SCL) ──┤          │   │
                     │          │   │
              ┌──────┴──────┐   │   │
              │  MLX90614   │   │   │
              │  SDA   SCL  │   │   │
              └─────────────┘   │   │
              ┌─────────────┐   │   │
              │  MAX30102   │   │   │
              │  SDA   SCL  │───┘   │
              └─────────────┘       │
              ┌─────────────┐       │
              │  MPU6050    │       │
              │  SDA   SCL  │───────┘
              └─────────────┘
```

**关键：整条I2C总线只需要一对 4.7kΩ 上拉电阻！不要在每个传感器上重复放。**
